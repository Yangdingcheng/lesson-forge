# LessonForge 教案工作台 📐

按 2025–2026 年教师备课工作流的**前沿共识**做的本地工作台：不比「一键生成」，比的是
**接地、分步、可改、回流**——生成器正在免费化（Gemini/微软/ChatGPT 教育版相继免费），
真正稀缺的是与真实教材课标的对齐、教师在环的共创、以及可审计的质量校验
（依据两项独立 RCT 与多家产品的一手资料，调研结论见仓库内的设计稿说明）。

## 四个前沿做法，都做成了能跑的功能

- **接地（RAG）**：把教材、课标、教参文本放进 `kb_library/`，本地 BM25 检索（纯标准库、中文二元组），
  生成时注入相关片段并标注 `[来源: 文件 · 第N块]`，不是凭空编。
- **分步共创**：五步工作流——学习目标 → 环节大纲 → 环节细化 → 材料 → 对齐校验，
  每步都是「生成草案 → 教师编辑 → 确认锁定」才往下走，像英国 Oak Aila 的关键点暂停审校。
- **可审计的对齐校验**（市面产品的最大空白）：学习目标带 ID（G1、G2…），环节、习题、量规全部引用目标 ID，
  程序确定性审计：孤儿目标、无评价目标、野习题、裸环节、课标未覆盖、量规缺口、时间超限，
  输出一张「目标 × 环节/习题/量规」对齐矩阵与覆盖率。不宣称「对齐 100%」，只给你可核查的矩阵。
- **回流**：每节课的课后反思存档，同单元下一课生成目标时自动带入上节反思与未覆盖缺口。

## 两个教师真实需求

- **旧教案改造是第一入口**：`--remix` 把旧教案文本解析成结构化工程并跑对齐校验——
  示例旧教案一测就暴露 14 个缺口（目标没人承载、无习题无量规、无课标标注…），再逐项补齐。
- **分层**：环节任务与习题按 基础/提高/挑战 三层生成。

## 快速开始（零依赖）

```bash
python main.py --demo     # 全流程演示：勾股定理五步共创 + 对齐校验 + 导出教案 + 旧教案改造
python main.py --web      # 打开工作台 http://127.0.0.1:8770
python run_tests.py       # 25 项核心测试
```

双模式：配置了 AI（OpenAI 兼容，DeepSeek 等）就走 AI 生成（强制结构化 JSON、目标绑定课标）；
没配 Key 自动落到**模板模式**——结构完整、对齐可过，内容留「（请教师修改）」标记。
把 `config.example.json` 复制为 `config.json` 填 Key 即可切换。

## 工作流一览

```
课题信息（学科/年级/教材版本/课标条目）
  → ① 学习目标（绑定课标条目）→ 教师确认
  → ② 环节大纲（每环节承载目标 ID、总时长核账）→ 教师确认
  → ③ 环节细化（教师活动/学生活动/设计意图/三层任务）
  → ④ 材料（习题按目标×层级、评价量规、板书，一体生成）
  → ⑤ 对齐校验（矩阵 + 缺口清单）
  → 导出标准格式教案（Markdown，可粘贴进 Word）+ 课后反思回流
```

## 目录

```
main.py                  CLI（--demo / --web / --remix）
lesson_forge/
  models.py              工程模型：目标/环节/习题/量规/反思 + JSON 持久化
  kb.py                  知识库：分块 + BM25 检索 + 引用溯源
  workflow.py            五步生成器（AI 提示词 + 模板回退 + 反思回流）
  alignment.py           对齐校验与矩阵（纯函数）
  remix.py               旧教案解析
  exporter.py            标准教案 Markdown 导出
  ai_client.py           OpenAI 兼容客户端（标准库）
  webui.py               本地工作台（标准库 http.server）
kb_library/              放你的教材/课标/教参文本
samples/                 示例语料（勾股定理）与一份旧教案
DESIGN.md                设计稿：调研结论如何落到功能上、哪些噱头不做
```

## 说明

- 示例语料为演示检索而编写的概括性文本，并非教材或课标原文；正式使用请放入你有权使用的材料。
- 本项目为个人学习与教学辅助工具：AI/模板生成的教案必须经教师审校后使用，对齐校验只保证结构贯通，不替代专业判断。
